# Project governance manifest

- Original binding references: `binding_source_lines` is the lossless observation
  view; existing preparation/page authority owns cache identity and fresh-page
  publication. `binding_source_regions` reuses immutable-document grid/token/cell
  proof; `binding_source_references` owns pure source-scope/primary-cell replay in
  the sole writer/catalog/formal gate. No second cache, model, queue, writer or
  scientific repair script. Primary IDs, method references and explicit nonfinal
  roles stay distinct. Current Binding9/binder18 are separate from unchanged raw2/
  OCSR2/preparation1/visible12/activity12/epoch21/coverage8/SAR14/manual/API/SQL/
  dependencies. Document-wide reference inventory is not proof of detection recall
  or chemical correctness. Older epoch entries below retain release context only.

- Physical-header ownership: `cell_header_lines` supplies bounded original row
  geometry and existing-engine observation under the shared cell reader;
  `cell_header_proof` replays that envelope. `activity_header_proof` uses existing
  schema/identity rules, shared by the producer and saved artifact validation.
  Known original/detector/native/unit/endpoint/target conflicts cannot be voted
  away; newline/unit identity and all original observations survive. No alternate
  parser, engine, writer, queue, dependency or science edit. Activity12/epoch21/
  coverage8 update derived semantics independently of binding8/binder17/visible12/
  preparation1/rawObs2/rawOCSR2/SAR14/API/SQL/manual history. Bounds are eight lines,
  12pt per line, 8million pixels/cell; unknown/over-bound sources require review.
  Controlled checks do not prove universal patent or chemical acceptance.

- Grid-role ownership: `activity_grid_roles` supplies only positive literal
  characterization semantics; `activity_grid_role_observation` reuses existing
  source geometry/native/cell/coordinate OCR; `activity_grid_role_proof` replays
  all original cells and valid conflicts through the single coverage/core/Web/SAR
  authority. Unknowns remain unresolved; no page-absence/result-reference waiver,
  alternate parser/store/queue/model or scientific value rewrite. Header context
  and original boundary prefixes share the same layout/continuation authority.
  `cell_ocr_scores` is the sole initial/reread numeric confidence guard. Binding8/
  binder17/activity11/epoch20/coverage7 change only derived proof; original/raw/
  manual, visible12/preparation1/rawOCSR2/SAR14/API/SQL/dependencies stay intact.
  Native/raster/mixed controls do not certify universal coverage or chemistry.

- Caption-line ownership: `cell_line_coverage.py` provides bounded original-frame
  ink coverage to the existing `cell_ocr_lines` coordinator, only for captions.
  `cell_caption_identity.py` rechecks detector claims in observation and serialized
  numbered proof; overlapping fragments are not independent complete labels.
  Valid original conflicts/nonfinal roles remain explicit. Binder17/binding8 change
  derived ownership only; original assets/OCR/model/manual history,
  visible12/preparation1/rawOCSR2/SAR14/API/SQL/dependencies/queues stay.
  Controlled fonts/negative/resource cases are not real-patent scientific acceptance.

  QA/Web consume original binding/metadata facts. Original source hash/stereo and

  chemical edits. Independent preparation epoch1 enters stage identity while raw
  OCSR observation2 and other scientific epochs/API/SQL/dependencies/queues/models

  rewritten; malformed current proof is rejected. No provider call or automatic
  real-task run. Controlled tests do not imply universal scientific acceptance.
  The existing frontend compound-label helper localizes only known generated
  placeholders; no raw/source/manual identifier, correction or data contract changes.
